# Portfolio Web — Martín Román

Personal portfolio website showcasing my work as a game developer and software engineer.

**Live:** https://mrkamikazee.github.io/PortfolioWeb/

---

## About
Since a significant portion of my professional work has been developed under **Non-Disclosure Agreements (NDAs)** within corporate environments, I cannot expose the raw source code of those projects.

To bypass this restriction while still demonstrating my engineering capabilities, this portfolio is structured around **Technical Case Studies**. Instead of just showing gameplay, the site focuses on:
*   **Architectural Breakdowns:** Explanations of design patterns (State Machines, Observers, Singletons, MVC/MVP), data management, and system scalability.
*   **Video Demonstrations:** Embedded high-quality video walkthroughs of specialized systems running in real-time.
*   **Problem-Solving Focus:** Detailed analysis of real optimization and development challenges faced during production and how they were resolved.
*   **Additional Data Files:** Additiona data files like GDD.
